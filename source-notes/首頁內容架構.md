# 首頁內容架構

## Demo 目標

做一個單頁首頁，讓 Jay 可以直觀看到「如果南臺流音系首頁變成比較有作品感、產業感、音樂現場感」會長什麼樣子。

這不是正式學校網站，也不替代原 CMS；所有正式連結都導回原網站。

## 第一版建站技術建議

先用最簡單的靜態網站：

```text
site/index.html
site/styles.css
site/script.js
```

不使用大型框架，原因：

- Demo 只有首頁。
- GitHub Pages 部署最簡單。
- 後續若要改為正式提案，可以再轉成 React/Vite。

## 上 GitHub 前檢查

- 所有圖片路徑都相對於 `site/` 正確。
- 手機版導覽可展開。
- 首頁首屏不被圖片原本文字與疊字互相干擾。
- 最新訊息連結全部導向正式網站。
- Footer 清楚標示 demo 性質或導回正式網站，避免被誤認為學校正式新版。
